# 输出规范

## 默认 Markdown

```markdown
# 标书审核报告

## 总体结论
- 综合风险：高 / 中 / 低
- 审核范围：……
- 关键结论：……

## 风险统计
| 等级 | 格式 | 内容 | 合计 |
|---|---:|---:|---:|
| 高风险 | 0 | 0 | 0 |

## 问题清单
### 1. [高风险][内容] 问题标题
- 位置：第 12 页，3.2 技术参数表第 4 项
- 事实：……
- 证据：招标要求“……”；投标响应“……”
- 影响：……
- 建议：……

## 要求矩阵
仅在提供招标文件时输出。

## 审核限制与人工复核项
- ……
```

## JSON

用户要求机器可读结果时使用以下结构。所有字段都应存在；没有内容时使用空数组或空字符串。

```json
{
  "summary": {
    "risk_level": "高|中|低",
    "conclusion": "总体结论",
    "coverage": ["格式", "内容", "招标响应"]
  },
  "statistics": { "high": 0, "medium": 0, "low": 0 },
  "findings": [
    {
      "id": "F-001",
      "severity": "高风险|中风险|低风险",
      "category": "格式|内容",
      "title": "问题标题",
      "location": "页码、章节或表格",
      "fact": "观察到的事实",
      "evidence": ["证据 1", "证据 2"],
      "impact": "可能影响",
      "suggestion": "可执行修改建议",
      "source_rule": "招标条款位置；无明确条款时为空字符串",
      "confidence": "高|中|低"
    }
  ],
  "requirement_matrix": [
    {
      "requirement": "招标要求",
      "source": "招标文件位置",
      "mandatory": true,
      "response": "投标响应摘要",
      "response_location": "投标文件位置",
      "status": "符合|部分符合|不符合|未响应|无法判断",
      "evidence": "判断证据"
    }
  ],
  "limitations": ["未覆盖项及原因"],
  "manual_review": ["建议人工终审的事项"]
}
```

## 质量检查

交付前确认：

- 统计数字与问题清单一致。
- 每条问题都有位置、事实、证据、影响和建议。
- 高风险问题均有明确招标依据或清晰的实质性风险说明。
- 没有编造页码、条款、证书、金额或参数。
- 相同根因未重复计数。
- 限制项真实反映文件和工具能力。
